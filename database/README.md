# 🗄️ Database Documentation (GroupDesk V2)

## 📌 परिचय (Introduction)
इस फ़ोल्डर को सिर्फ **Data Storage** (डेटा रखने) के लिए बनाया गया है। 
अगर भविष्य में आप `SQLite` या किसी लोकल JSON डेटाबेस का इस्तेमाल करते हैं, तो उसकी फ़ाइलें (`.db` या `.json`) इसी फ़ोल्डर में रखी जाएँगी।

वर्तमान में हम **MongoDB (Mongoose)** का इस्तेमाल कर रहे हैं। MongoDB का डेटा आपके कंप्यूटर के बैकग्राउंड सर्विस (MongoDB daemon) द्वारा अपने डिफ़ॉल्ट फ़ोल्डर (जैसे Windows में `C:\data\db`) में स्टोर होता है।

> **महत्वपूर्ण:** कोडिंग की फ़ाइलें (`models.js`, `connection.js`) को `backend` फ़ोल्डर में रखा गया है ताकि आर्किटेक्चर साफ़ रहे (MVC Pattern)।

## 📊 डेटाबेस स्कीमा (Database Models)
GroupDesk V2 में 3 मुख्य टेबल्स (Collections) काम कर रही हैं। (इनका कोड `backend/models.js` में है)

### 1. **Group (ग्रुप्स का डेटा)**
- `id`: WhatsApp का ग्रुप ID (जैसे 123456@g.us)
- `name`: ग्रुप का नाम
- `enabled`: (Boolean) क्या बॉस ने इस ग्रुप को कर्मचारियों के लिए चालू (ON) किया है?
- `anonCounter`: यह याद रखता है कि इस ग्रुप में कितने अज्ञात (Unknown) लोगों ने मैसेज किया है (ताकि उन्हें R1, R2, R3 नाम दिया जा सके)।

### 2. **Message (चैट हिस्ट्री)**
- `groupId`: किस ग्रुप का मैसेज है।
- `senderDisplay`: मैसेज भेजने वाले का नाम (या R1, R2)। असली नंबर यहाँ स्टोर या UI को सेंड नहीं होता है।
- `type`: मैसेज कैसा है? (`text`, `image`, `video`, `audio`, `document`)
- `text`: मैसेज का टेक्स्ट या मीडिया का कैप्शन।
- `mediaUrl`: अगर कोई फोटो है, तो वह सर्वर में कहाँ सेव है उसका लिंक।
- `quotedMsg`: अगर किसी ने रिप्लाई (Reply) किया है, तो किस मैसेज का रिप्लाई किया है, उसकी जानकारी।
- `reactions`: अगर किसी ने मैसेज पर इमोजी (👍) लगाया है।

### 3. **Alias (प्राइवेसी और नंबर छुपाना)**
- `groupId`: ग्रुप का ID।
- `participantId`: भेजने वाले का असली नंबर (WhatsApp Number)।
- `alias`: उसे क्या नाम दिया गया है? (जैसे R1)
- **लॉजिक:** जब भी कोई नया नंबर ग्रुप में मैसेज करता है जिसका नाम सेव नहीं है, तो बैकएंड इस टेबल में चेक करता है। अगर वह नया है, तो उसे एक नया Alias (R+1) दे दिया जाता है। इससे किसी भी कर्मचारी को असली नंबर कभी नहीं दिखता।

## 🚀 नया डेवलपर कैसे समझे?
अगर आपको डेटाबेस में कोई नया फीचर (जैसे Admin Users) जोड़ना हो:
1. `backend/models.js` में जाकर नया Mongoose Schema बनाएँ।
2. `backend/server.js` में उसका API लिखें।
3. डेटा अपने आप MongoDB में सेव होने लगेगा।
